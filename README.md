Proyecto mínimo Next.js (Flowy)

Instrucciones rápidas:

1. Instala dependencias:

```bash
pnpm install
```

2. Ejecuta en desarrollo:

```bash
pnpm dev
```

3. Abre http://localhost:3000

Empieza editando `src/app/page.tsx` y `src/app/layout.tsx`.

Esta plantilla está pensada como punto de partida: limpia, con `pnpm` y soporte TypeScript.
